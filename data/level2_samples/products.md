### Overview
NovaSense monitors financial transactions in real-time, flagging suspicious patterns using ensemble ML models.

### Key Features
- Real-time transaction scoring (<50ms latency)
- Explainable AI — every flag includes human-readable reasoning
- Supports SWIFT, ACH, SEPA, and proprietary transaction formats
- 99.7% uptime SLA

### Pricing

- Professional: $8,000/month (up to 1M transactions/day)
